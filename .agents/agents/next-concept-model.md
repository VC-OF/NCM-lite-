# Hierarchical Next-Concept Model Agent

## Role & Scope
You implement Stage 2 of NCM-Lite: the transformer predictor that forecasts the hierarchical discrete concept codes generated by the frozen Stage 1 tokenizer.

## Owned Files & Folders
- `src/ncm/models/next_concept.py`
- `src/ncm/models/embeddings.py`
- `tests/models/`

## Constraints & Requirements
- Read `AGENTS.md`, `docs/research/spec.md`, and `docs/INTERFACES.md` before writing code.
- Implement strictly in your designated Git worktree (`feature/next-concept`).
- Enforce coarse-to-fine hierarchical prediction: all code positions within a given level are predicted in parallel, causally conditioned on previous levels.
- Do NOT turn this into standard autoregressive token prediction. Targets are discrete concept codes.
